Линейный иммуноблот (EUROLINE, recomBlet, Лайн-Блот): БЕЗ электрофореза — очищенные/рекомбинантные антигены нанесены линиями в фиксированных позициях на нитроцеллюлозной полоске. Сыворотка 30–60 мин → конъюгат anti-human IgG/IgM → субстрат → линии. 10–20 антигенов на полоске (профиль). Чтение по критериям. Автоматизация: EUROBlotOne, BlotCycler; сканеры EurolineSCAN.

Преимущество перед Western: рекомбинантные белки сохраняют конформационные эпитопы (SDS их денатурирует).

Dot blot: образец точкой на мембрану, без разделения — «есть/нет».

Исторический Western в диагностике ВИЧ/сифилиса (полосы по массам, критерии CDC) — вытеснен линейными.

Иерархия: скрининг (ELISA/IFA — чувствительность) → подтверждение (блот — специфичность). Серая зона (indeterminate) → повтор через 2–4 нед / ПЦР / клиника.
